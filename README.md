# analise-de-desempenho-comercial
Projeto desenvolvido com Excel e Power BI para resolver o problema de queda na margem de lucro em relação ao crescimento das vendas. Envolve auditoria de dados brutos, simulação de cenários de negócios (What-If), modelagem dimensional em Star Schema, métricas em DAX e dashboard interativo focado em tomada de decisão.
